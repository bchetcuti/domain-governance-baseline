# Domain Governance Baseline change history

This change history records substantive changes to the authored governance artefact. Routine styling, accessibility, implementation and maintenance changes do not require an entry unless they alter meaning or use.

## Supporting public surface - 4 September 2026

- separated the canonical authored Baseline homepage from the interactive working review;
- established `/review/` as the private local Baseline Review route while retaining `/` as the preferred citation and project identity;
- kept the ten canonical Version 1.0 questions, six optional follow-on themes, local state model, review-summary semantics and no-score / no-assurance boundaries unchanged; and
- updated reference and machine-facing navigation so users can distinguish understanding or citing the Baseline from actively working through it.

This is a v1.x-compatible information-architecture improvement, not a new assessment product or canonical version change.

## Supporting public surface - 11 August 2026

- added a fictional Australian NFP worked walkthrough connecting the unchanged ten-question Baseline to evidence, governance interpretation, decisions, organisational records, accountable follow-up and recurring review;
- aligned the existing worked domain register, authority review, authorised-sender register and action log to the walkthrough scenario, and added a concise worked incident-exercise record; and
- preserved the ten canonical questions, five-guide boundary, no-score position and open uncertainties.

## Version 1.0 - 9 August 2026

Version 1.0 establishes the current ten-question checklist as the canonical citable baseline.

- fixed the ten questions as the stable v1 baseline;
- established preferred citation metadata;
- made the authored governance content available for reuse under CC BY 4.0;
- added a public citation and stewardship surface;
- added a fixed v1.0 reference edition;
- established the versioning rule that v1.x may improve explanation, practice guidance and supporting artefacts without materially changing the canonical questions;
- reserved v2.0 for a future decision to add, remove or materially reframe a canonical question.

No baseline question, score, rating, assurance claim, new guide, platform capability or external integration was introduced by this release.
